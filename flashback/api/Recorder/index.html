Recorder

Server-side recorder. Tracks tagged instances and writes transforms, spawn/despawn, watched properties, animations, gameplay events and custom channels into a replay buffer.

Transforms are delta-compressed: after a full sample, each moving tick costs a few bytes of quantized position delta plus a yaw delta for upright entities. Parts jointed to a tracked ancestor (character limbs, welded attachments) are not written at all; the playback rig's own joints and animations move them.

Records the named properties of every tracked instance that IsA className. Initial values are written on spawn and changes are written each tick. Limbs and other jointed sub-parts are skipped; their look comes from the playback rig.

_pollTracks​

</>
Recorder._pollTracks(
self: Recorder,
e: Entity
) → ()

Tracks are polled each tick instead of trusting Stopped, which does not fire reliably for tracks replicated from a client, so a stop lands within one tick of the track going idle.

_flushSnapshot​

</>
Recorder._flushSnapshot(
self: Recorder,
e: Entity
) → ()

Writes the entity's geometry once. The capture taken at spawn is held back while descendants keep arriving (a character still loading limbs and accessories) and replaced by a fresh capture once the entity has been quiet for a second, so a replay carries one snapshot per entity instead of one per arrival. Pending captures are flushed on untrack, stop and finalize; the player keeps the last snapshot it decodes.

) → {string}?

Properties the entity's watch list names for an instance: the union of every listed class it IsA (so BasePart.Color and Part.Shape both apply to a Part). Nil when nothing matches.
