Serializer

Growable little-endian buffer writer and reader, rotation quantization and string interning. Shared by the Recorder and the Player.

Functions​

newWriter​

</>
Serializer.newWriter(initial: number?) → Writer

Creates a writer with an initial capacity. The buffer doubles as needed.

writeRotation​

</>
Serializer.writeRotation(
w: Writer,
cf: CFrame
) → ()

Writes the rotation of a CFrame as an axis-angle vector quantized to 3 x i16.

rotationFromDelta​

</>
Serializer.rotationFromDelta(
x: number,
y: number,
z: number
) → CFrame

Rotation delta from three i8 axis-angle components in 1/ROT_Q radians.

isYawOnly​

</>
Serializer.isYawOnly(cf: CFrame) → boolean

True when the CFrame is a pure rotation about the world Y axis, the common case for characters and vehicles.

toBase64​

</>
Serializer.toBase64(data: buffer) → string

Base64 encodes a buffer so it can live inside JSON such as plugin settings.

newStringTable​

</>
Serializer.newStringTable() → StringTable

Interns strings to 1-based ids so the op stream only carries u16 references.
