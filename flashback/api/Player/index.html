Player

Decodes a replay buffer into a tick-indexed timeline and drives proxy instances with interpolation. Supports play, pause, seek and speed. Works on the client and inside Studio edit mode.

Functions​

readHeader​

</>
Player.readHeader(blob: buffer) → Header

Reads only the header of a replay buffer without decoding the op stream.

_characterTemplate​

</>
Player._characterTemplate(

Fetches a character model once per user and reuses clones afterwards, so rewinding never waits on the network or spawns duplicates.

</>
Player._trackSpeed(
self: Player,
recorded: number
) → number

Speed an animation track should run at: its recorded speed scaled by the playhead speed, and zero while paused.

step​

</>
Player.step(
self: Player,
dt: number
) → ()

Advances playback by dt seconds and renders. Called automatically each frame unless autoStep is false. In Studio edit mode animation tracks do not advance on their own, so animators are stepped here. In reverse the playhead runs backwards; transforms interpolate either way, and proxies are rebuilt from spawn only when the playhead crosses a tick that carries discrete state.

setReverse​

</>
Player.setReverse(
self: Player,
reverse: boolean
) → ()

When on, playing runs the playhead backwards from its current position.

setLoop​

</>
Player.setLoop(
self: Player,
loop: boolean
) → ()

When on, reaching the end restarts from the first tick instead of pausing.

seek​

</>
Player.seek(
self: Player,
tick: number
) → ()

Jumps to a tick. Seeking backwards rebuilds proxies so discrete state is replayed from spawn. Seeking forwards applies entity state without firing event or channel handlers. Ticks start at 1, so seeking to 0 shows the first recorded state rather than empty proxies.

_rewind​

</>
Player._rewind(
self: Player,
tick: number
) → ()

Rebuilds every proxy so discrete state is replayed from spawn up to tick.

links​

</>
Player.links(self: Player) → {Link}

Everything in this replay that can be linked to an instance in Studio: recorded models (link a prefab to clone it instead of the snapshot) and the unions inside them. Link with Snapshot.link and reload.
