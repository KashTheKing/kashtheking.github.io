Plugin guide

The widget follows the Studio theme and has everything needed to record without writing code.

Header​

Shows whether the Flashback module is installed. Click the text to select it in the Explorer, or the X to uninstall it.

Install module​

Copies Flashback into ReplicatedStorage, tags it FlashbackModule, and adds a FlashbackStudio Script to ServerScriptService. You can move the module anywhere under ReplicatedStorage, ServerStorage or ServerScriptService; the plugin and the server script find it by tag.

The script serves a Studio-only RemoteFunction so the plugin can record play tests from the client view. It does nothing outside Studio.

Record​

The big button starts and stops a session. Elapsed time and estimated size update live, and the replay saves on stop. Existing session names are never overwritten without an explicit Overwrite click.

Recording in a play test happens on the server and captures gameplay. Recording in edit mode captures whatever you move by hand.

Tracked instances​

Tags or untags the current Explorer selection. Player characters are always tracked.

Settings​

Session name, storage, tick rate, keyframe interval and which properties to capture. Settings persist across Studio runs and can be saved as named presets.

Storage is one of:

  • DataStore, with an optional name suffix to keep environments apart. Needs Studio API access.
  • HTTP server, see Storage.
  • This computer: the replay is base64-encoded into the plugin's settings file. Keep it to short sessions.

Replays​

A scrolling list of stored sessions with Load and Delete on each. A loaded replay shows a scrubber, play/pause and speed presets. When Moon Animator is loaded, Export to Moon Animator appears too; see Moon Animator.
