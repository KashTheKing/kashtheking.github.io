Flashback

Record gameplay on the server. Play it back anywhere.

Get startedGet the plugin

Server-side recording

Player characters are tracked automatically. Tag anything else and it is captured too, animations included.

Full playback control

Play, pause, seek to any second and change speed, or drive the clock yourself for cinematic cuts.

One plugin, no code

Install the module, record a play test, tag instances and browse saved replays from a widget that follows the Studio theme.

Compact binary format

Delta ticks with periodic keyframes keep replays small, with a live size estimate while you record.

Store it anywhere

DataStore with 3 MB chunking, any HTTP backend, or the plugin's local settings file for quick tests.

Moon Animator export

Turn a replay into a Moon Animator 2 save and polish it into a cutscene or trailer shot.

Kill cams in a few lines

Record on the server, save to the DataStore, and play the replay back on any client. Proxies are built for you, with physics off and scripts stripped, so playback never touches the live game.

Recording guide →
local Flashback = require(game.ReplicatedStorage.Flashback)

-- server: record the round
local rec = Flashback.Recorder.new({ tickRate = 15 })
rec:start()
rec:event("Kill", { killer = 1, victim = 2 })
Flashback.Store.save("match_1", rec:stop())

-- client: watch it back in slow motion
local player = Flashback.Player.new(Flashback.Store.load("match_1"))
player:setSpeed(0.5)
player:play()
