Studio

Server-side controller used by the Studio plugin during play tests. The plugin lives in the client DataModel, so it drives recording through a RemoteFunction that only exists in Studio.

Functions​

createRecorder​

</>
Studio.createRecorder(opts: StartOptions) → Recorder.Recorder

Builds a recorder from plugin settings. Shared with the plugin's local backend so edit-mode and play-mode recordings match. watch is a list such as BasePart.Color,Humanoid.Health (see Recorder.parseWatch).

saveBlob​

</>
Studio.saveBlob(
data: buffer,
key: string,
target: Target,
force: boolean
) → SaveResult

Saves a finished recording, refusing to overwrite unless forced.

serve​

</>
Studio.serve() → ()

Creates the RemoteFunction and starts serving. No-op outside Studio.
