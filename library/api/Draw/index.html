Draw

This item is only intended to be used by the module's authors. Private

The wave mesh's per-frame drawing, run in parallel by the Renderer's workers.

Functions​

Load​

</>
Draw.Load(
d: Data,
share: number,
shares: number
) → ()

Takes over a new build: the whole mesh's data, and which share of it this copy draws.

Unload​

</>
Draw.Unload() → ()

Forgets the build (the Renderer destroyed it).

ReadFrame​

</>
Draw.ReadFrame(published: SharedTable) → Frame

The frame the Renderer published, as a plain table (reused).

Step​

</>
Draw.Step(p: Frame) → number?

The maths of one update for this share: safe in parallel (it writes nothing). Returns false when there is nothing to draw (no build, or the frame is another build's), else how many vertices it updated.

Write​

</>
Draw.Write() → ()

The writes of the last Step: serial only (Bone.Transform and EditableMesh can't be written in parallel).

Height​

</>
Draw.Height(
x: number,
z: number,
inv: number
) → number

World Y of the surface as drawn at (x, z) (see Renderer): the wave sum at spacing inv, the weather layers there and obstacles, inverted like Waves.Height so the sideways shove is accounted for. Gathers its own layers: call it before Step, not during.

WaterColour​

</>
Draw.WaterColour(now: number) → (
number,
number,
number
)

The water's colour from the global weather: halfway between its deep and shallow colours. Gathers its own layers: call it before Step, not during.
