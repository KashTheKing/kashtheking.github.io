Init

A module loader for Roblox games. Drop modules in folders; Init loads, initializes and starts them in order.

Get Started →

No code to set up

Install the Init Framework plugin, press Setup, and your game has a loader, boot scripts and folders. Add modules with one click from templates.

Made for AI

An AI skill, copy-paste prompts and raw templates let Claude, Cursor or ChatGPT install Init and write modules the right way.

Predictable startup

Folders load in the order you list them. Every Init runs before any Start, and OnPlayerAdded, Step, OnCharacterAdded and friends are wired up for you.

What it looks like

-- ServerScriptService/InitServer (Script)
local Init = require(ReplicatedStorage.Packages.Init)

Init.start({
	{ Folders = { ReplicatedStorage.Network } },
	{ Folders = { ReplicatedStorage.Services, ServerScriptService.Services }, Predicate = Init.matchesName("Service$") },
})

-- ServerScriptService/Services/CoinService
local CoinService = {}

function CoinService.Init(self) self.Coins = {} end           -- own state only
function CoinService.Start(self) end                           -- other modules are ready
function CoinService.OnPlayerAdded(self, player) self.Coins[player] = 0 end
function CoinService.OnPlayerRemoving(self, player) self.Coins[player] = nil end

return CoinService
